# macro

보조도구와 자동화 함수 모음
Collection of automation functions and tools

## cheetsheet

CLI 도구 사용 요약
Summary of CLI tool usage

- ffmpeg: 비디오 변환 Video conversion
- yt-dlp: 유튜브 다운로드 Youtube download

## devtool

개발자용 코드 관련 도구
Code-related tools for devs

- codecount: 로컬 저장소나 원격 저장소 코드 규모 표시기 Code size indicator for local or remote repositories
- embed_bin: 작은 데이터를 소스코드에 임베딩 Embed small data into source code
- tkcolor: tkinter 색상 표시 Tkinter color display

## filetool

파일 관리/변환 도구
File management/conversion tools

- filediv: 파일을 여러 개로 쪼개거나 합치기 Split or merge files
- pdfobject: PDF 문서를 변환하거나 페이지 편집 Convert PDF documents or edit pages
- piczip: 이미지이면서 동시에 압축 파일인 배포 파일 생성 Create distribution file that are both image and zip file
- yas_assist: YAS-lite 운용 Operate YAS-lite

## imgtool

이미지 관련 도구
Image-related tools

- capture: 전자책이나 문서 자동 캡쳐 아카이브 Automatic capture archive for ebooks or documents
- mapgen: 점과 선 기반의 3D 지도 제작기 Point and line-based 3D map maker
- stitcher: 2D 화면 캡쳐 이미지 병합 Merge 2D screen capture images

## sign_assist

윈도우 전자서명 도구
Windows digital signature tool (deprecated)
